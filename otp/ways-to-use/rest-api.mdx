The EngageLab OTP service provides a set of RESTful APIs that allow you to programmatically create templates, deliver OTPs, and verify codes.

Follow the steps below to start using the REST APIs.

<Steps>
  <Step title="Create an API Key">
    Before you can call any EngageLab OTP APIs, you need to generate an API Key to authenticate your requests.

    1. Log in to the [EngageLab console](https://www.engagelab.com/accounts/signup).
    2. Enter the OTP sub-portal and select your application.
    3. Navigate to **API Keys** in the left sidebar.
    4. Click **Create API Key** to generate a new `dev_key` and `dev_secret`.

    <Warning>
      Your `dev_secret` is highly sensitive. Keep it secure and never expose it in client-side code or public repositories.
    </Warning>
  </Step>

  <Step title="Authentication">
    EngageLab OTP APIs use HTTP Basic Authentication. You must include an `Authorization` header in all your API requests.

    The header is constructed using your `dev_key` and `dev_secret` encoded in Base64:

    ```http
    Authorization: Basic ${base64_auth_string}
    ```

    The `${base64_auth_string}` is generated by Base64-encoding your `dev_key` and `dev_secret`, separated by a colon (`:`): `base64(dev_key:dev_secret)`.

    For more details, see the [Authentication](/otp/api/authentication) guide.
  </Step>

  <Step title="Call the APIs">
    Once you have your API Key and understand the authentication mechanism, you can start calling the APIs. All API endpoints use the base URL `https://otp.api.engagelab.cc`.

    Here are the primary APIs you can integrate:

    <CardGroup cols={2}>
      <Card title="OTP Delivery" icon="paper-plane" href="/otp/api/otp-delivery.json">
        Generate verification codes through the EngageLab platform and deliver them according to your template strategy.
      </Card>
      <Card title="OTP Verification" icon="shield-check" href="/otp/api/otp-verification.json">
        Verify the One-Time Passwords submitted by your users securely.
      </Card>
      <Card title="Custom OTP Code Delivery" icon="envelope-open-text" href="/otp/api/custom-otp-code-delivery.json">
        Send pre-generated verification codes to users if you prefer to generate the codes yourself.
      </Card>
      <Card title="Custom Message Delivery" icon="message" href="/otp/api/custom-message-delivery.json">
        Deliver custom message content (such as notifications or marketing messages) to a mobile phone number or email address.
      </Card>
      <Card title="Template Management" icon="layer-group" href="/otp/api/template.json">
        Programmatically create, delete, and retrieve template configurations for your OTP service.
      </Card>
    </CardGroup>
  </Step>
</Steps>
