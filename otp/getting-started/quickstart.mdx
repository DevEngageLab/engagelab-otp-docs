Get started quickly with the EngageLab OTP service.

<Steps>
  <Step title="Sign up and log in">
    Sign up for an EngageLab account at [engagelab.com/accounts/signup](https://www.engagelab.com/accounts/signup) and log in.
  </Step>
  <Step title="Enable OTP service">
    After logging in, enable the OTP service and enter the OTP sub-portal.
  </Step>
  <Step title="Create an application">
    In the OTP sub-portal, create a new application.
  </Step>
  <Step title="Create a template">
    Go to the application console, navigate to **Template**, and create a template. You can choose Email, SMS, WhatsApp, or Voice as your OTP delivery channel.
  </Step>
  <Step title="Create an API Key">
    Go to **API Keys** and create a new API Key.
  </Step>
  <Step title="Send your first OTP">
    Go to **Send OTP**, select the template and API Key you just created, and send your first OTP.
    API documentation: [OTP Delivery](/otp/api-reference/otp-delivery).
  </Step>
  <Step title="Verify the OTP">
    Go to **Verify OTP**, select your API Key, fill in the `message_id` and `code`, and complete the OTP verification.
    API documentation: [OTP Verification](/otp/api-reference/otp-verification).
  </Step>
  <Step title="Top up your account">
    The EngageLab OTP service operates on a pay-as-you-go model. We recommend topping up your account balance before using the service in production to ensure uninterrupted delivery.
  </Step>
</Steps>
