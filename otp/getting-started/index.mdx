## Prerequisite: Create an API Key

Currently, we require a human to create an EngageLab account. Once you have an account, you'll need to create an API key in the OTP console. With an API key (`dev_key` and `dev_secret`), your agent can perform all OTP delivery and verification tasks.

<Info>
  To send an OTP, you'll also need to create a **Template** in the EngageLab console. While agents can manage templates via the [Template API](/otp/api/create-template), you may find it easier to create and approve your first template in the dashboard.
</Info>

## Agent Skills

Agent Skills give Cursor, Claude Code, and Windsurf the knowledge to handle OTPs automatically : sending codes, verifying them, processing webhooks.

One command to install, then just ask your agent:

## Quick Start Guides

Throughout our documentation, we provide quick start guides for common tasks. Copy the prompt below for your agent to get started instantly.

<Accordion title="Example agent prompt for sending and verifying OTPs" icon="terminal">
  EngageLab provides two primary endpoints for OTP workflows:

  | Action | Endpoint | Use Case |
  | --- | --- | --- |
  | **Send OTP** | `POST /v1/messages` | Generate and deliver a verification code to a user. |
  | **Verify OTP** | `POST /v1/verifications` | Verify the code submitted by the user. |

  ## Quick Start

  1. **Detect project language** from config files (package.json, requirements.txt, etc.)
  2. **Install SDK** (preferred: `engagelab-otp` for Node.js/Python) or use REST APIs.
  3. **Implement Authentication** - HTTP Basic Auth using `base64(dev_key:dev_secret)`.
  4. **Implement Webhooks** - For production, set up callback endpoints to track delivery status.

  ## Best Practices (Critical for Production)

  ### Error Handling

  | Code | Action |
  | --- | --- |
  | 400 | Fix request parameters (e.g., invalid phone number format), don't retry |
  | 401, 403 | Check API key or IP whitelist, don't retry |
  | 429 | Rate limited - retry with exponential backoff |
  | 500 | Server error - retry with exponential backoff |

  ### Minimal Example (Node.js SDK)

  ```javascript
  const { OTPClient } = require('engagelab-otp');

  const otp = new OTPClient('YOUR_DEV_KEY', 'YOUR_DEV_SECRET');

  // 1. Send OTP
  const { message_id } = await otp.send('+6591234567', 'your-template-id', {}, 'en');
  console.log('Sent message ID:', message_id);

  // 2. Verify OTP
  const { verified } = await otp.verify(message_id, '123456');
  if (verified) {
    console.log('Verification successful!');
  }
  ```
</Accordion>
