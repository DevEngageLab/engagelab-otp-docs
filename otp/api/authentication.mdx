EngageLab OTP APIs use HTTP Basic Authentication. You must include an `Authorization` header in all your API requests.

## Authorization Header

Construct the `Authorization` header using the following format:

```http
Authorization: Basic ${base64_auth_string}
```

### Generating the Auth String

The `${base64_auth_string}` is generated by Base64-encoding your `dev_key` and `dev_secret`, separated by a colon (`:`).

**Algorithm:**

```text
base64(dev_key:dev_secret)
```

<Note>
  You can find your `dev_key` and `dev_secret` in the **APIKey** section of the EngageLab OTP console. Keep your `dev_secret` secure and never share it in publicly accessible code.
</Note>
